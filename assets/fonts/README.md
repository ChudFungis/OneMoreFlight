# Local Baloo 2

`baloo_2.ttf` is the unmodified variable font from the [official Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/baloo2), downloaded 2026-10-17. SIL Open Font License 1.1 is included in `OFL.txt`. No runtime font download is required.

The four FontVariation resources select 500/600/700/800 with numeric OpenType `wght` tag 2003265652. Godot 4.7.2 did not apply string-keyed coordinates in native rendering; tests verify the rendered RID coordinates. Keep antialiasing enabled for smooth type. These resources are reused by FlightStyle rather than duplicating font files.
